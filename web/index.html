Teapot Shader

The Utah teapot built from its 32 Bezier patches and rendered three ways, ported from my 2017 OpenGL coursework to WebGL 2. Source on GitHub.

Your browser doesn't support WebGL 2, so the teapot can't be drawn.

Drag to rotate · shift-drag to pan · scroll to zoom · arrow keys when focused

Mode

Each patch is a 4×4 grid of control points. The mesh is evaluated with Bernstein polynomials at the chosen number of steps; fewer steps show the patch structure.

Light
Material

Sphere mapping: each pixel looks up the texture with its reflection vector, the way OpenGL's GL_SPHERE_MAP texture generation did in the original.
